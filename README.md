# 🖥️ System Info & Health Checker

A Python-based system monitoring tool that provides real-time insights into system performance, including CPU, memory, disk usage, and running processes.

---

## 🚀 Features

- CPU usage monitoring
- Memory (RAM) usage tracking
- Disk space analysis
- System and OS information
- Network details (IP, hostname)
- Top processes by CPU usage
- Health warnings (high usage alerts)
- Export system report to file

---

## 🛠️ Technologies Used

- Python 3
- psutil
- socket
- platform
